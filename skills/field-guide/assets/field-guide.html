01

Give the reader a start.

Open with what the guide helps someone do. Keep background close to the action it explains, and make the first step small enough to try.

  1. Name the outcome.

    Use the reader's language. Explain what becomes possible after following the guide.

  2. Show what to bring.

    List the inputs or context needed for that action. Keep optional preparation clearly optional.

  3. Describe what happens next.

    Give the reader a visible result to look for, including any limits that matter.

02

Make the next step concrete.

Examples pair an action with an expected result. These cards demonstrate the pattern; their buttons copy text without running or submitting anything.

Context → a first step

Describe the situation

I have [current material]. I want to help [reader] do [action]. Start with the smallest useful next step.

Expect: a shared understanding of the reader, the material, and the immediate outcome.

An action → a visible result

Try one example

Walk through one example using [sample input]. Explain what I should see and what would mean something went wrong.

Expect: an observable result and a useful explanation of a failure case.

An observation → useful feedback

Explain what you noticed

I expected [result], but I observed [what happened]. Help me understand the difference and the next useful check.

Expect: a concrete question to investigate, grounded in an observation.

Today's work → tomorrow's start

Leave a return point

Record what changed, what was checked, what is still open, and the next agreed action.

Expect: enough context to continue without reconstructing the whole conversation.

The filters demonstrate an optional component. For a short guide, remove the filter bar and result count and show every example.

03

Help them review the result.

Use comparisons when two ideas belong side by side. Keep the main explanation in prose so the page has a comfortable reading rhythm.

What the reader brings

  • The outcome they want to reach.
  • Existing material and relevant context.
  • Observations and questions.

What the guide provides

  • A practical sequence of actions.
  • Examples with expected results.
  • Limits and a useful next step.
  • Can I find my starting point?The first action is visible and understandable without reading every section.
  • Can I tell whether it worked?The example includes the result to look for and any uncertainty.
  • Can I return later?The guide has clear sections, meaningful links, and enough context to continue.

Keep qualifications attached to the claim. If an example is proposed, incomplete, or unverified, tell the reader where that distinction affects their next action.

04

Keep context nearby.

What should I change in this starter?

Replace the specimen content, title, description, brand, navigation, and examples. Keep only the components that serve the actual guide. Preserve the source material's facts and limits.

Does a guide need these interactions?

No. Copy controls help with reusable examples; filters help when there are enough examples to browse. The reading content stays available without JavaScript.

What happens when I print it?

All examples and supplementary explanations are included. Navigation and interactive controls are hidden so the result reads as a document.

This starter includes its styles, script, and icon. It needs no external fonts or services to render.
